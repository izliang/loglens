# 01 变量与类型

## 这一节要会什么

- `let` 默认不可变，加 `mut` 才能改
- **遮蔽（shadowing）**：同名 `let` 覆盖，还能换类型
- 整数/浮点/布尔/字符，以及 `as` 与 `parse` 两种转换
- 元组 `(T1, T2)` 和数组 `[T; N]`
- `String` 与 `&str` 的根本区别

## 运行

```bash
./run.sh 01
```

## 关键概念

### 1. 不可变是默认值

```rust
let x = 5;
x = 6;          // ❌ 编译错误
let mut y = 5;
y = 6;          // ✅
```

Rust 把"可变"当成一种需要显式声明的权力，这能让并发和阅读都更安全。

### 2. 遮蔽 vs 可变

| | 遮蔽 `let x = ...` | 可变 `let mut x` |
|---|---|---|
| 能否改值 | ✅ | ✅ |
| 能否改类型 | ✅ | ❌ |
| 旧值 | 被新绑定遮住，仍在作用域结束后释放 | 直接改同一个变量 |

### 3. 整数类型速查

| 有符号 | 无符号 | 位数 |
|---|---|---|
| `i8` | `u8` | 8 |
| `i16` | `u16` | 16 |
| `i32` | `u32` | 32 |
| `i64` | `u64` | 64 |
| `i128` | `u128` | 128 |
| `isize` | `usize` | 跟平台一致（64 位系统是 64） |

默认整数是 `i32`，默认浮点是 `f64`。`usize` 专门用于下标和长度。

**溢出**：debug 模式 panic，release 模式回绕。要安全就用 `checked_add`（返回 `Option`）或 `saturating_add`（封顶）。

### 4. 元组 vs 数组

| | 元组 `(i32, f64)` | 数组 `[i32; 3]` |
|---|---|---|
| 元素类型 | 可以不同 | 必须相同 |
| 长度 | 编译期固定 | 编译期固定 |
| 访问 | `t.0` / 解构 | `a[0]` |
| 扩容 | 不能 | 不能（要 `Vec`） |

需要长度可变就用 `Vec<T>`（第 06 节）。

### 5. String 还是 &str

| | `&str` | `String` |
|---|---|---|
| 所有权 | 借用，不拥有 | 拥有 |
| 可否增长 | 否 | 是（`push_str`） |
| 存放位置 | 字面量在只读区 | 堆 |
| 典型来源 | `"字面量"`、切片 | `String::from(..)`、`format!` |

规则很简单：**函数参数优先用 `&str`（更通用），需要拥有或修改时用 `String`**。

`len()` 返回**字节数**，中文一个字 3 字节，所以 `"中文".len() == 6`，而 `chars().count() == 2`。

## 试着改改

1. 把 `let x = 5;` 改成 `let mut x = 5; x = 6;`，确认能编译。
2. 写 `let s = "中文"; println!("{}", s.len());`，再改成 `s.chars().count()`，理解字节和字符。
3. 把 `arr[0]` 改成 `arr[10]`，运行看 panic 信息（注意这是运行时错误，不是编译错误）。
4. 用 `"3.14".parse::<f64>()` 解析浮点，把 `expect` 里的提示换成自己的话。

## 常见坑

- `let x = 5;` 之后又写 `x = 6;` 是最常见的第一个编译错误。
- 数组下标越界是**运行时** panic，编译器管不了。
- `as` 转换会静默截断：`300 as u8 == 44`，别拿它做校验。
