# 00 最小可运行程序

## 这一节要会什么

- 一个 Rust 程序的最小结构：`fn main() { ... }`
- `println!` / `print!` / `eprintln!` / `dbg!` 的区别
- `{}`、`{:?}`、`{:#?}`、`{:.2}` 这几种格式占位符
- 用 `cargo` 跑起来

## 运行

```bash
./run.sh 00
# 等价于
cargo run -p hello
```

## 预期输出（节选）

```
你好，Rust！
这一行不会换行
初学者 学习 Rust 的第 1 天
...
调试输出: (3, 4)
二进制: 101010
保留两位: 123.46
```

## 关键点

| 写法 | 作用 |
|---|---|
| `println!("{}", x)` | 显示格式，给人和终端看 |
| `println!("{:?}", x)` | 调试格式，几乎所有类型都能打 |
| `println!("{:#?}", x)` | 调试格式 + 换行缩进，看嵌套结构 |
| `print!` / `eprint!` | 不换行 / 走标准错误 |
| `dbg!(expr)` | 打印表达式和位置，并把值返回，适合临时排查 |

`!` 表示这是**宏**而不是普通函数，所以能接受可变数量的参数。学习期不用深究宏原理。

## 项目结构

```
00-hello/
├── Cargo.toml   # 清单：包名、版本、edition
└── src/main.rs  # 入口，必须有 fn main()
```

`edition = "2021"` 是语言版本，类似"第几版标准"，不影响学习顺序。

## 试着改改

1. 把 `println!` 换成 `print!`，观察输出粘在一起。
2. 打印一个 `(String, i32)` 元组，先用 `{:?}` 再用 `{:#?}`。
3. 用 `{:08.3}` 打印 `123.456`，猜猜输出是什么，然后验证。
4. 故意写 `println!("{}", 1, 2);`，读一遍编译器的报错——后面你会经常见到它。

## 命令速查

```bash
cargo run         # 编译并运行
cargo check       # 只检查类型，不生成可执行文件（最快）
cargo build       # 编译到 target/debug/
cargo build --release   # 优化编译，跑得快的正式版
cargo clean       # 清掉 target
```
