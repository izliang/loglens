# 02 函数与控制流

## 这一节要会什么

- 定义函数、参数、返回值，理解**返回值是最后一个表达式**

## 关键概念

### 1. 语句 vs 表达式

| | 语句 | 表达式 |
|---|---|---|
| 产生值 | 否 | 是 |
| 例子 | `let x = 1;`、`fn f() {}` | `1 + 2`、`if ... {..} else {..}`、`{ ... }` |

函数的返回值就是**函数体这个大表达式**的值，所以最后一行**不能加分号**：

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b      // ✅ 返回 a+b
    // a + b;  // ❌ 加了分号就变成语句，函数返回 ()，类型不匹配
}
```

这是新手最常踩的坑，报错通常是 `expected i32, found ()`。

### 2. if 是表达式

```rust
let size = if n > 5 { "大" } else { "小" };
```

两个分支必须返回**同一种类型**。Rust 不像 C 那样把 `0` 当假，条件必须真的是 `bool`。

### 3. 三种循环怎么选

| 循环 | 什么时候用 |
|---|---|
| `for x in 集合` | **默认选择**，遍历集合/范围 |
| `while 条件` | 条件驱动的循环 |
| `loop` | 只有 `break` 能退出，需要返回值时用 |

`loop { ... break 值; }` 是少数能把值带出循环的写法。

### 4. match 必须穷尽

```rust
match code {
    200 => "成功",
    _ => "其他",   // 少这一行就编译不过
}
```

编译器会检查是否覆盖所有可能，这是 Rust 相比 `switch` 最大的优势。分支按顺序匹配，所以 `_` 放最后。

### 5. 常用模式

| 模式 | 含义 |
|---|---|
| `0..=99` | 闭区间 |
| `a \| b` | 或 |
| `(0, y)` | 解构元组 |
| `n @ 1..=5` | 绑定到 `n` 同时判断范围 |
| `(x, y) if x > 0` | 带条件守卫 |
| `_` | 忽略，兜底 |

## 常见坑

- 函数最后一行多写一个分号 → 返回值变成 `()`。
- `if` 分支返回类型不一致（一个 `i32` 一个 `&str`）。
- `for i in 1..5` 是 1,2,3,4，**不含 5**；含 5 要写 `1..=5`。
- `break` 只能跳出循环，不能像某些语言那样用来"跳出函数"，那是 `return` 的活。
